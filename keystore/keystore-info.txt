ChatSphere - Android release signing keystore
================================================

This keystore signs your app for release. Every update you ever upload
to Google Play must be signed with the SAME keystore, or Play Console
will reject it. Keep this folder somewhere safe and backed up (a
password manager or private cloud storage, not just this one copy).

File:        chatsphere-release.keystore
Alias:       chatsphere
Store password: ChatSphere#20267161
Key password:   ChatSphere#20267161
Validity:    30 years (until 2056)

A COPY of this same .keystore file is already placed at
client/android/app/chatsphere-release.keystore, and a matching
client/android/keystore.properties file already references it - so
building a signed release APK/AAB in Android Studio or via
`./gradlew assembleRelease` works immediately, with nothing extra to
configure.

Both of those files are excluded via .gitignore, so if you push this
project to GitHub they will NOT be uploaded (good - keeps the keystore
out of your git history). This means the GitHub Actions workflow can't
see them either, so to get signed builds from GitHub Actions, add these
as repo secrets (Settings -> Secrets and variables -> Actions -> New
repository secret):

  ANDROID_KEYSTORE_BASE64   -> base64 of chatsphere-release.keystore
                               (run: base64 -i chatsphere-release.keystore | tr -d '\n')
  ANDROID_KEYSTORE_PASSWORD -> ChatSphere#20267161
  ANDROID_KEY_ALIAS         -> chatsphere
  ANDROID_KEY_PASSWORD      -> ChatSphere#20267161

Want to change these passwords? Just regenerate the keystore yourself
before your first Play Store upload (you have not uploaded anything
yet, so this is a good time if you'd rather set your own password):

  keytool -genkeypair -v -keystore chatsphere-release.keystore \
    -alias chatsphere -keyalg RSA -keysize 2048 -validity 10950

Then update client/android/keystore.properties (and the GitHub
secrets above) to match whatever passwords you choose.
